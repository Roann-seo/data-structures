C++ 比较器知识点（sort、优先队列 priority_queue）
## 1.sort 的比较函数（普通数组 /vector）

`sort(起始,结束,cmp)`，左闭右开区间。

### ①升序（默认，从小到大）
sort(a.begin(),a.end());
bool cmp(int x,int y){
    return x<y;
}
②降序（从大到小）
bool cmp(int x,int y){
    return x > y; //大的放前面
}
③结构体排序（考试高频）
struct Work{
    int d; //截止时间
    int p; //利润
};
//按利润从大到小排序
bool cmp(Work a,Work b){
    return a.p > b.p;
}
sort(w+1,w+n+1,cmp);
## 2. 优先队列 priority_queue【重点！和 sort 是反过来！】

> 
> ✅超级重要考点：
> `priority_queue`的比较器：返回 true 代表**优先级更低，放堆底**。
> `priority_queue` 默认是**大根堆**，堆顶是最大元素。
//大根堆（默认），top取最大
priority_queue<int> q;

//小根堆，top取最小，写法固定
priority_queue<int,vector<int>,greater<int>> q;
struct Work{
    int d;
    int p;
};
//小根堆：利润小的放堆顶
struct Cmp{
    bool operator()(Work a,Work b){
        return a.p > b.p; 
        //a.p>b.p返回true →a优先级低，下沉，小值留在堆顶
    }
};
priority_queue<Work,vector<Work>,Cmp> q;
### 记忆口诀

1. `sort(cmp)`：return true → **放前面**
2. `priority_queue<Cmp>`：return true → **压到底下（优先级低）**

> 
> 同一个结构体，sort 降序写`a.p>b.p`；小根堆优先队列也要写`a.p>b.p`，不要搞混！

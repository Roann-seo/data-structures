 # 异或 (^) 交换两个变量

 > 
 > 异或符号：`^`，手写图里的`∧`就是异或运算符
 > **异或规则：相同为 0，不同为 1，等价无进位二进制相加**
 > 异或核心公式：

 1. `n ^ n = 0` 同一个数异或自己等于 0
 2. `0 ^ n = n` 0 异或任何数等于它本身
 3. 满足交换律、结合律
 int a = 甲;
 int b = 乙;

 a = a ^ b;  // a = 甲^乙，b=乙
 b = a ^ b;  // b = (甲^乙) ^ 乙 = 甲 ^ (乙^乙) = 甲 ^0 =甲，现在b变成甲
 a = a ^ b;  // a = (甲^乙) ^ 甲 = 乙 ^(甲^甲)=乙^0 =乙，现在a变成乙
## 重要坑点

**a、b 必须是两块不同的内存地址！**
如果两个变量指向同一个地址（比如数组 `swap(arr[i], arr[i])`，i==j）：

```
a = a ^ a → a=0
后续运算全部变成0，直接把原值清零，数据直接销毁。
```

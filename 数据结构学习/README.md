## 编译运行

```bash

gcc "线性表学习/1.线性表的顺序存储.c" -o seqlist.exe -std=c11 -fexec-charset=UTF-8
gcc "链表学习/2.链表.c" -o linkedlist.exe -std=c11 -fexec-charset=UTF-8

# 栈

# 队列
gcc "队列知识点/14.循环队列.c" -o queue.exe -std=c11 -fexec-charset=UTF-8
```

或在 VS Code 中使用 Code Runner 直接运行。
